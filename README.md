# Northern Ireland Rental Hub

**Project Objective:** Build a clean, modern, and trustworthy rental marketplace prototype for Northern Ireland that completely replaces chaotic Facebook listings. 

**Today's Milestone (UI Design Focus):** 

Please build a beautifully designed, premium, and minimal "Tenant Passport" dashboard screen. Focus 100% on a responsive, mobile-first frontend design layout using real, clean placeholder content (no code placeholders). Do not connect a live database yet.

**Layout and Sections to Include:**

1. **Header:** A simple navigation bar with a placeholder logo, a notification bell, and a user profile dropdown.

2. **Passport Status Card:** A prominent top banner showing the tenant's current verification status with a green badge that reads "Ready-to-Rent (Verified)".

3. **The Core Credentials Grid (Cards):**

   - *Identity Card:* Shows a verified checkmark next to "Government Photo ID Verified".

   - *Income & Employment Card:* Shows a summary layout for monthly income proof and employer reference status.

   - *Character Reference Card:* Visual indicator showing a completed reference from a previous landlord.

4. **The Property Preference Tracker:** A section displaying the tenant's search filters, specifically highlighting local NI infrastructure preferences like: "Preferred Utility: Bulk Oil / Gas Heating with Empty-in, Full-out agreement".

5. **Action Button:** A large, rounded primary Call-to-Action button at the bottom that reads: "Share Passport to Landlord".

**Aesthetic Tone:** Minimalist, clean, secure, and professional. Use soft greys, white cards with subtle shadows, and emerald green purely for "Verified" success elements.
